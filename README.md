# Data Analytics Master Roadmap

A complete, practical guide to business problem-solving, SQL, Python, and Power BI—anchored to a single running hospital staffing dataset.

---

### Course Tracks

* **Module 0: Business Thinking**  
  Translate ambiguous business problems into measurable questions using the 5W1H framework, anomaly detection, and root-cause analysis.
* **Module 1: MySQL Mastery**  
  Relational schema design, filtering, aggregations, multi-table joins, data cleaning, and window functions.
* **Module 2: Python for Data Analysis**  
  NumPy vectorization, Pandas data cleaning, reshaping, and exploratory visualizations with Seaborn.
* **Module 3: Power BI & DAX**  
  Power Query ETL, star schema design, evaluation contexts, and essential DAX measures (`CALCULATE`, `DIVIDE`, time intelligence).

---

### How to Use This Portal

1. **Follow the Sequence:** Work topic by topic using the **Next Topic →** button at the bottom of each page.
2. **Run Every Query:** Copy the code blocks directly into MySQL Workbench, Jupyter Notebook, or Power BI.
3. **Compare Expected Outputs:** Verify your results against the output tables provided on each page before proceeding.
