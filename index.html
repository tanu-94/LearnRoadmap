1. GROUP BY with HAVING

Definition

GROUP BY aggregates rows with identical values into summary rows. HAVING filters those aggregated groups based on a summary condition.

Plain-English Meaning

"Group transactions into buckets (like cities), calculate summary totals for each bucket, then show only the buckets that beat our target."

Exact Syntax 
SELECT column_name, AGG_FUNCTION(metric)
FROM table_name
WHERE individual_row_filter
GROUP BY column_name
HAVING AGG_FUNCTION(metric) > condition;

2. DENSE_RANK() Window Function

Definition

Assigns a rank to each row within a partition ordered by a specific expression, without skipping any numbers when duplicate tie values occur.

Plain-English Meaning

"Rank items within separate groups from #1 to last place without gaps (1, 2, 2, 3 instead of 1, 2, 2, 4)."

Exact Syntax 
DENSE_RANK() OVER (
    PARTITION BY partition_column 
    ORDER BY metric_column DESC
) AS rank_alias

1. df.groupby().agg()

Definition

Splits a DataFrame into groups based on specified keys, executes distinct summary functions across different columns, and returns a grouped summary.

Plain-English Meaning

"Take a giant spreadsheet, group it by region, run different math formulas on different columns at the same time, and give me the clean summary."

Exact Syntax 
df.groupby('dimension_col').agg({
    'numeric_col1': 'sum',
    'numeric_col2': 'mean',
    'id_col': 'nunique'
}).reset_index()

Imputes or replaces missing values (`NaN`/`None`) in a DataFrame using a specified scalar value, replacement dictionary, or computed statistic.

"Fill blank cells with a sensible number (like the median or zero) so downstream formulas and calculations don't break."

Exact Syntax

1. =XLOOKUP()

Definition

Searches a range or an array for a match and returns the corresponding item from a second range or array. Defaults safely to exact match.

Plain-English Meaning

"Find this specific ID in Column A, and pull the corresponding value from Column B—regardless of whether Column B is to the left or right."

Exact Syntax 
=XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found], [match_mode])
